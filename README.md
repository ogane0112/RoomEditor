# RoomEditor

3DスキャンしたGLBファイルをブラウザで読み込み、家具(メッシュ)の選択・移動・回転・色変更・削除を行える3D部屋編集ツールです。
要件は [docs/requirements.md](docs/requirements.md) を参照してください(本実装はフェーズ1)。

スキャンデータはすべてブラウザ内で処理・保存(IndexedDB)され、サーバーには送信されません。
DRACO圧縮GLB用のデコーダもアプリに同梱しており、外部CDNへのリクエストは発生しません。

## 機能

| 機能 | 操作 |
|---|---|
| GLBインポート | 「GLBインポート」ボタン、またはウィンドウへのドラッグ&ドロップ |
| サンプル | 「サンプルの部屋を開く」(スキャンデータがなくても試せます) |
| 視点操作 | 左ドラッグ: 回転 / 右ドラッグ: 平行移動 / ホイール: ズーム |
| 選択 | 3Dビューのクリック、または右パネルのオブジェクト一覧 / Esc で解除 |
| 移動・回転 | ギズモをドラッグ。W: 移動モード / E: 回転モード |
| 色変更 | 右パネルのカラーピッカー・パレット。「元の色に戻す」で解除 |
| 削除 | 右パネルの削除ボタン / Delete キー(一覧から選んで復元も可能) |
| Undo / Redo | Ctrl+Z / Ctrl+Shift+Z(Ctrl+Y) |
| 保存 | 保存ボタン / Ctrl+S。部屋一覧から複数の部屋を切り替え・名前変更・削除 |

### スマホ

スマホでは右パネルが画面下部に移動し、ツールバーはアイコン表示になります。

- タップ: 選択 / 1本指ドラッグ: 視点の回転 / 2本指: 平行移動・ズーム
- ギズモはタッチ用に大きめに表示されます。移動・回転の切り替えはツールバーのボタンで行います
- オブジェクト一覧は下部パネルの「オブジェクト一覧」をタップすると開きます
- GLBは「GLBインポート」から端末内のファイルを選択します(部屋一覧画面)

## 開発

```bash
npm install
npm run dev        # 開発サーバー
npm test           # ユニットテスト (vitest)
npm run typecheck  # 型チェック
npm run build      # dist/ に静的ファイルを出力
```

`vite.config.ts` で `base: './'` を指定しているため、`dist/` はGitHub Pagesなど任意のパス配下の静的ホスティングにそのまま置けます。

## 技術構成

Vite + React + TypeScript / React Three Fiber + drei / Zustand / IndexedDB (idb) / Tailwind CSS

```
src/
  App.tsx                 画面切替・ドラッグ&ドロップ・キーボードショートカット
  types.ts                Room / RoomObject の型
  store/editorStore.ts    編集状態と Undo/Redo 履歴 (Zustand)
  lib/db.ts               IndexedDB への保存・読込
  lib/rooms.ts            部屋の新規作成・読込・保存
  three/gltf.ts           GLBの読込、編集可能メッシュの抽出、編集状態の反映
  three/sampleRoom.ts     サンプル部屋GLBの生成
  components/             Viewer(3D) / Toolbar / SidePanel / RoomList
```

### 設計メモ

- **オブジェクトID**: GLBのルートからの子インデックスのパス(例: `0/3/1`)。名前が重複・空でも一意で、同じGLBを再読込すれば同じIDになります。
- **保存形式**: `rooms` ストアにメタ情報・各オブジェクトの編集状態・サムネイル、`glbs` ストアにGLB本体を分けて保存し、一覧表示で大きなGLBを読み込まないようにしています。GLB本体は初回保存時のみ書き込みます。
- **色変更**: マテリアルはメッシュごとに複製するため、他のメッシュに影響しません。色を上書きしている間はテクスチャを外して指定色をそのまま表示し、「元の色に戻す」で元のテクスチャ・色に戻ります。
- **Undo/Redo**: ギズモのドラッグやカラーピッカーの連続操作は、確定時に1件の履歴にまとめます。履歴はセッション中のみ保持します。
- **制約**: 選択はGLB内のメッシュ単位です。1メッシュに複数の家具が含まれるスキャンでは個別に選択できません(要件定義 8章)。
